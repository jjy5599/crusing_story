# 🚢 Mindful Cruise - ADHD 집중 앱

ADHD 사용자를 위한 디지털 디톡스/집중 앱입니다. 바다 항해 크루즈 컨셉의 게이미피케이션을 통해 집중 시간을 관리하고 상품 추첨 티켓을 획득할 수 있습니다.

## 주요 기능

### ✅ 구현된 기능 (프로토타입)

1. **집중 모드 (항해)**
   - 15분~120분 집중 시간 설정
   - 실시간 타이머 및 진행도 표시
   - 화면 꺼짐 감지 및 일시정지
   - 5분 확인 시간 제한 및 지연 페널티

2. **왕복 항로 시스템**
   - 영일만항 ↔ 울릉도 (400분 완주)
   - 목적지 도착 시 티켓 획득
   - 자동 반대 방향 항로 전환

3. **낚시 게임**
   - 물고기 낚기로 포인트 획득
   - 희귀도별 물고기 (일반/레어/에픽/전설)
   - 낮은 확률로 티켓 직접 획득

4. **포인트 시스템**
   - 200 포인트로 티켓 1장 교환

5. **상품 추첨**
   - 티켓으로 추첨 참여
   - 추첨 이력 저장 및 확인
   - 다양한 상품 (스타벅스, 도서 상품권, 영화 예매권 등)

6. **데이터 영속성**
   - localStorage를 통한 진행도 저장
   - 앱 재시작 후에도 데이터 유지

## 기술 스택

- **Frontend**: React 19 + TypeScript
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS
- **Icons**: lucide-react
- **Storage**: localStorage

## 시작하기

### 1. 패키지 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:5173`을 열어 앱을 확인하세요.

### 3. 프로덕션 빌드

```bash
npm run build
```

빌드된 파일은 `dist/` 폴더에 생성됩니다.

### 4. 프로덕션 미리보기

```bash
npm run preview
```

## 사용 방법

### 집중 모드 시작

1. 홈 화면에서 집중 시간을 설정합니다 (15-120분)
2. "출항하기" 버튼을 클릭합니다
3. 타이머가 시작되며 배가 바다를 항해합니다
4. 집중 시간이 완료되면 5분 이내에 "하선 확인"을 클릭하세요
5. 5분 초과 시 인정 시간이 10%로 감소합니다

### 낚시 게임

1. 홈 화면에서 "낚시하러 가기" 버튼 클릭
2. "낚시 시작" 버튼 클릭
3. 입질이 오면 "잡기!" 버튼을 빠르게 클릭
4. 물고기를 잡아 포인트를 획득하세요
5. 매우 낮은 확률로 티켓을 직접 획득할 수 있습니다

### 상품 추첨

1. 티켓을 1장 이상 보유한 상태에서 "상품 추첨" 클릭
2. "추첨하기" 버튼을 클릭하여 티켓 1장 사용
3. 당첨 여부 확인
4. 추첨 이력에서 과거 결과 확인 가능

### 포인트 교환

- 홈 화면 하단의 "포인트 상점"에서 200 포인트로 티켫 1장 교환 가능

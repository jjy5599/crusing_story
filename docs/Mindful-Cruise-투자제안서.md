# 🚢 Mindful Cruise 투자 제안서

## "스마트폰에 빠진 우리 손자, 손녀를 구해줄 앱입니다"

---

## 📌 1. 한 줄 요약

**Mindful Cruise**는 스마트폰에 중독된 청소년과 성인들이 **집중력을 기르고 공부나 업무에 몰입할 수 있도록 도와주는 앱**입니다.

쉽게 말씀드리면, **"휴대폰을 내려놓고 있으면 상품을 받을 수 있는 앱"**입니다.

---

## 🌊 2. 이 앱이 뭔가요? (쉬운 설명)

### 앱의 기본 개념

요즘 젊은 사람들이 스마트폰을 손에서 놓지 못합니다. 
5분도 안 되어 유튜브, 인스타그램, 게임을 하느라 공부나 일에 집중을 못 합니다.

**Mindful Cruise**는 이런 문제를 해결합니다.

**작동 방식:**
1. 사용자가 "15분~2시간" 동안 집중할 시간을 정합니다
2. 그 시간 동안 **휴대폰을 켜놓고 다른 앱을 쓰지 않으면** 
3. **"추첨 티켓"**을 받습니다
4. 티켓으로 **스타벅스 커피, 도서 상품권, 영화 예매권** 등을 받을 수 있습니다

### 왜 "크루즈 배"인가요?

- 휴대폰을 내려놓고 집중하는 시간 동안, **화면에는 아름다운 바다를 항해하는 배가 보입니다**
- 영일만항(포항)에서 울릉도까지 가는 **400분(약 6시간 40분)**을 채우면 티켓 1장을 받습니다
- 마치 실제로 배를 타고 여행하는 기분을 느끼면서 집중할 수 있습니다
- 울릉도에 도착하면 다시 돌아오고, 계속 왕복하며 티켓을 모읍니다

**즉, 공부나 업무를 하면서 "가상 크루즈 여행"을 하고, 상품도 받는 일석이조 앱입니다.**

## 📊 3. 왜 지금 이런 앱이 필요한가요? (시장 트렌드)

### 3-1. 스마트폰 중독 문제

| 통계 | 수치 |
|------|------|
| 한국인 하루 평균 스마트폰 사용 시간 | **4시간 23분** |
| 청소년 스마트폰 과의존 비율 | **40.1%** (10대) |
| ADHD(주의력결핍 과잉행동장애) 진단 증가율 | **매년 10% 이상** |

**요즘 젊은이들은 5분도 집중을 못 합니다.** 
SNS 알림, 유튜브 영상, 게임에 계속 주의가 분산됩니다.

### 3-2. "디지털 디톡스" 트렌드

**디지털 디톡스**란? 
스마트폰이나 인터넷을 일정 시간 끊고 쉬는 것입니다.

- 전 세계적으로 "스마트폰 끊기" 운동이 확산 중
- 미국, 유럽에서는 **"집중력 앱"** 시장이 급성장
- 한국에서도 **"공부 앱", "타이머 앱"** 인기 상승

### 3-3. 게이미피케이션(Gamification) 트렌드

**게이미피케이션**이란?
공부나 운동 같은 일에 **게임 요소를 넣어서 재미있게 만드는 것**입니다.

예시:
- 만보기 앱: 걸으면 포인트를 주고, 상품을 줍니다
- 다이어트 앱: 살을 빼면 뱃지를 줍니다
- **Mindful Cruise**: 집중하면 티켓을 주고, 상품 추첨에 참여합니다

**"재미가 있어야 꾸준히 합니다"** - 이것이 게이미피케이션의 핵심입니다.

## 💪 5. 이 앱의 강점은 무엇인가요?

### 5-1. 다른 집중 앱과의 차별점

| 기존 집중 앱 | Mindful Cruise |
|------------|----------------|
| 그냥 타이머만 있음 | **아름다운 바다 항해 영상** 제공 |
| 완료해도 보상 없음 | **티켓으로 실제 상품** 획득 |
| 금방 지루해짐 | **게임 요소(낚시, 추첨)**로 재미 유지 |
| 강제로 막아서 스트레스 | **자발적 참여** 유도 |

### 5-2. 핵심 경쟁력

**① 지역 특색 (영남 지역 기반)**
- 포항 영일만항 ↔ 울릉도 실제 항로 사용
- 영남 지역 사용자에게 친숙함
- 향후 다양한 지역 항로 추가 가능 (부산↔제주, 여수↔거문도 등)

**② 다양한 활동**
- 집중 모드: 공부/업무할 때
- 낚시 게임: 쉬고 싶을 때 물고기 잡아서 포인트 획득
- 상품 추첨: 티켓으로 실제 상품 당첨

**③ 심리적 동기 부여**
- 진행 표시줄로 "거의 다 왔다!" 느낌
- 목적지 도착 시 성취감
- 왕복 시스템으로 계속 동기 유지

**④ 기술적 완성도**
- 화면을 끄거나 다른 앱 사용 시 **자동 감지**
- 늦게 확인하면 **페널티** (진짜 집중했는지 검증)
- 데이터 저장으로 **기록 유지**

## 💰 6. 어떻게 돈을 버나요? (수익 모델)

### 수익 창출 방법 5가지

| 수익 모델 | 설명 | 예상 매출 비중 |
|-----------|------|--------------|
| **① 광고 수익** | 앱 내 광고 (구글, 카카오 애드핏) | 30% |
| **② 프리미엄 구독** | 월 4,900원 유료 구독 (광고 제거, 추가 기능) | 40% |
| **③ 기업 제휴** | 상품 협찬 (스타벅스, CGV, 교보문고 등) | 15% |
| **④ B2B 라이선스** | 학교, 기업에 단체 판매 | 10% |
| **⑤ 굿즈 판매** | 크루즈 캐릭터 굿즈 (선택) | 5% |

### 수익 모델 상세 설명

**① 광고 수익**
- 집중 시작 전, 종료 후에만 광고 노출 (집중 중에는 광고 없음)
- 15초 영상 광고 시청 시 추가 포인트 지급

**② 프리미엄 구독 (월 4,900원)**
- 광고 제거
- 추가 항로 해금 (부산↔제주 등)
- 특별 상품 추첨 참여
- 상세 통계 제공

**③ 기업 제휴**
- 스타벅스, CGV, 교보문고 등과 협력
- 기업은 **젊은 고객 확보**, 앱은 **실제 상품 제공**
- Win-Win 구조

**④ B2B 라이선스**
- 학교: "집중력 향상 프로그램"으로 도입
- 기업: 직원 생산성 향상 도구로 도입
- 학원: 학생 관리 도구로 도입

## 🔍 8. 왜 지금 투자해야 하나요?

### 시장 타이밍

1. **ADHD 인식 확산**: 더 이상 부끄러운 병이 아님, 적극적 관리 필요성 인식
2. **디지털 디톡스 트렌드**: 전 세계적으로 확산 중
3. **MZ세대 특성**: 재미있는 보상이 있어야 움직임
4. **경쟁 앱 부재**: 한국형 특화 집중 앱 없음

### 투자 포인트

| 포인트 | 설명 |
|--------|------|
| **① 사회적 가치** | 스마트폰 중독 해결, 청소년 집중력 향상 |
| **② 지역 특색** | 영남 기반, 지역 관광 연계 가능 |
| **③ 확장성** | 전국 항로, 해외 진출 가능 |
| **④ 반복 수익** | 구독 모델로 안정적 수익 |
| **⑤ 시장 성장** | 집중력 앱 시장 연 20% 성장 |

- 청소년 스마트폰 중독 예방
